# Web 像素农场生活游戏产品简报

## 一句话定位

一个无需登录的桌面 Web 俯视角像素农场生活游戏：玩家先建立自己的本地角色，再控制角色在固定农场和住宅内生活，并通过睡觉推进连续天数。

## 为什么做

产品价值来自直接、可感知的移动与生活节奏，不来自聊天、账号或内容平台。游戏本身必须完整可玩；现有论坛只是配套社区入口，不承担身份、进度或玩法。

旧 FableSpace、Character、StoryWorld、历史故事、关系、记忆和 LLM 产品合同已经放弃，不保留兼容入口、数据迁移或备用分支。

## 核心体验

```text
打开 /
  -> 首次选择男角色或女角色并命名；回访选择继续
  -> 搬进或恢复农场
  -> 用键盘移动并绕过树、石头和住宅
  -> 日内时钟持续推进
  -> 进入住宅
  -> 在床边交互
  -> 画面过渡，日期增加一天
  -> 在住宅内醒来
  -> 刷新或重新打开后从本地存档继续
```

### 首个可玩切片

- 原创标题/入住入口：男/女两种角色外观、1–12 字符名字、继续当前进度和安全重新开始。
- 一张紧凑固定农场：草地、路径、树、石头和住宅。
- 一个固定住宅室内：地板、墙体、门窗、基础家具和床。
- 玩家四向移动、停止、朝向与行走动画；WASD 和方向键都可用，斜向速度归一。
- 地图边界、树干、石头、墙体和占地家具可靠碰撞。
- 角色与树冠、家具等按脚底位置正确前后遮挡。
- `E` 或空格在交互边沿触发进门、出门和睡觉，长按不会重复结算。
- 显示角色名字、`第 N 天`、从早上 6:00 到凌晨 2:00 的日内时钟和必要交互提示；每 7 秒推进 10 分钟。
- 本地存档只记录版本、名字、稳定外观 ID、日期、日内分钟、场景和稳定出生点；合法 v2 补齐早上 6:00 后继续，合法 v1 进度补齐身份与时间后继续，损坏或未知 v3 回到角色创建且不复活旧档。
- 进出住宅不重置时间；在床边睡觉或到达凌晨 2:00 都只结算一次次日，并在住宅内于早上 6:00 醒来。
- 资源加载失败显示可理解的重试状态，不以空白画布兜底。

树和石头只是环境物件，不可砍伐、敲碎或掉落资源。

## 平台与技术

- 首发：桌面 Web 浏览器，键盘和鼠标。
- 外壳：React Router / Vite / TypeScript。
- 游戏运行时：Phaser 3，负责 Tilemap、动画、Arcade Physics、输入、镜头、深度与场景。
- 存档：浏览器 `localStorage`，不上传服务端。
- 公开入口：`/`，无需登录。

React 只持有入口状态和角色表单草稿，不持有逐帧游戏状态；Phaser 不调用旧 API、数据库、LLM、认证或论坛接口。

## 论坛关系

- 标题或游戏边缘提供清楚但低干扰的“论坛”或“社区”链接。
- 地址由 `VITE_FORUM_URL` 配置，默认 `https://pingxingxian.space`。
- 链接在新标签页打开并使用安全 `rel` 属性。
- 不嵌入帖子、好友、私信或论坛页面，不做注册提示、登录回跳、SSO、账号绑定或共享存档。
- 不登录论坛也能完整游玩首片。

## 美术与原创边界

- 首片统一采用 pixel-boy 官方 `Ninja Adventure - Asset Pack` 的实际需要部分；来源为官方 itch.io 页面，授权记录为 CC0。
- 男、女角色分别使用同一官方 CC0 固定提交中已核验并登记的玩家图集；两者只表示外观选择，不带职业或属性。
- 图片二进制不进入 Git；采用项先上传不可变对象存储并登记 `deploy/cdn/game-media-manifest.json`。
- 游戏名称、地图布局、角色表达、UI 和玩法呈现须原创；不得复制《星露谷物语》或其他游戏的资产、地图、文本、音乐、UI、品牌或其他受保护表达。

## 产品原则

- **先玩再扩展**：先交付农场、住宅和跨日闭环，再讨论经营内容量。
- **游戏独立**：论坛、账号、服务端和 LLM 不能成为正常游玩的前置条件。
- **状态单一归属**：Phaser 持有运行态，版本化本地存档持有跨刷新状态，React 不做镜像。
- **固定场景优先**：当前只做两张手工固定 Tilemap，不建设通用地图编辑器或程序生成平台。
- **可读手感优先**：碰撞体贴合脚下实体区域，遮挡按脚底排序，像素缩放清晰且不拉伸。
- **安全清退旧产品**：旧文件存在不代表兼容；删除前仍要精确审计。

## 当前明确不做

- 种地、作物、工具系统、砍树、碎石、采集和掉落。
- NPC、对白、日程、任务、商店、金币、背包、体力和经济。
- 小镇、矿洞、战斗、钓鱼、天气、季节、节日和复杂昼夜。
- 昼夜光照、体力、睡眠惩罚、复杂日历、复杂设置菜单、音频系统和多个存档槽；只迁移当前农场 v1/v2 到 v3 所需的身份与时间补全。
- 移动端触控、虚拟摇杆、手柄、多人和云存档。
- LLM、自由聊天、生成式 NPC、API、数据库、账号、SSO 或论坛身份集成。

上述玩法扩展不是首片的隐藏要求；未来只有在首片稳定后经单独批准，才进入新的产品与技术合同。

## 成功标准

- 打开根路由进入原创标题/入住或继续入口，公开界面不出现旧 FableSpace、Character 或 StoryWorld 入口。
- 玩家完成名字和外观后进入农场；刷新后能在继续入口看到自己的名字、外观与真实天数。
- 玩家能稳定完成农场移动、日内时间推进、进入住宅、睡觉或凌晨 2:00 自动结束当天、次日醒来和刷新恢复。
- 四向动画、碰撞、遮挡和画布缩放清晰可靠。
- 睡眠一次交互只增加一天，不会重复触发、卡死或出生在碰撞体内。
- 浏览器网络请求不包含旧 API、LLM、认证、数据库或论坛接口。
- 论坛链接在新标签页打开，且关闭论坛不影响游戏。
- 所有采用素材具有可核对的来源、授权、对象 URL、尺寸与 SHA-256；Git 跟踪图片二进制为零。
