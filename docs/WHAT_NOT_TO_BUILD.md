# Web 像素农场生活游戏明确不做清单

本文档防止新游戏退回旧产品或在首个可玩切片中无边界扩张。触碰永久禁区的需求默认拒绝；触碰首片范围锁的需求须另建任务并明确批准后才能实施。

## 核心判断

当前价值排序是：

- 直接操控与可靠手感 > 页面浏览或文字解释
- 农场、住宅、睡眠跨日闭环 > 同时堆叠大量系统
- 独立可玩 > 论坛、账号或服务端转化
- 固定可审查场景 > 通用玩法平台
- 清楚来源的原创/CC0 资产 > 模仿现有商业游戏

## 永久禁区

### 1. 旧 FableSpace 与兼容双轨

不做：

- 恢复 Character、StoryWorld、ReviewedStory、StoryRun、PlayerRole、关系、记忆、回访、历史故事或聊天产品。
- 保留旧首页、角色路由、StoryWorld API、旧数据迁移或隐藏备用入口。
- 为旧前端、后端、数据库、认证或媒体语义增加适配器。

允许：

- 只读审计旧引用，并在单独批准的清退任务中精确删除。
- 在删除数据或部署项前核对备份、影响和回滚边界。

### 2. LLM 与运行时生成

不做 LLM 对话、自由文本聊天、生成式 NPC、模型密钥、Prompt 管理、生成式任务或模型决定游戏状态。未来确定性脚本内容也必须另行批准，不得借“占位”恢复旧聊天运行时。

### 3. 现实地图与 LBS

不做现实经纬度、定位权限、地图首页、附近发现、现实 POI、路线规划或实时导航。

允许固定、虚构、手工设计的 Phaser Tilemap 游戏场景，包括农场、住宅以及未来经批准的小镇。Tilemap 不是现实地图产品。

### 4. 论坛平台化

不做论坛登录、注册漏斗、SSO、账号绑定、共享身份、共享存档、帖子嵌入、好友、私信、动态、排行榜或游戏内社区。

允许通过 `VITE_FORUM_URL` 提供一个普通 HTTPS 外链，在新标签页打开；链接不可影响游戏进度或权限。

### 5. 后端、数据库与云账号

当前产品不建设游戏 API、数据库、账号、云存档、跨设备同步、遥测画像或支付。不得为了保存名字、外观、`day`、`scene`、`spawn_id` 引入服务端。

未经用户明确授权不得连接任何旧数据库；不得创建迁移、表或清库启动逻辑。

### 6. 复制现有游戏

不复制《星露谷物语》或其他游戏的名称、品牌、地图布局、角色、对白、音乐、UI、图标、剧情或其他受保护表达，也不使用来源不明的拆包、镜像或二次打包素材。

允许参考“俯视农场生活模拟”这一抽象类型，并使用已核实授权的 Ninja Adventure CC0 素材形成临时视觉基线。

### 7. 过早的平台化

不做通用地图编辑器、ECS、玩法 DSL、插件系统、程序生成世界、大型全局状态库、第二套物理引擎或多游戏平台。两张固定场景可以用直接、清楚的数据结构实现。

## 首片范围锁

### 8. 不做经营与采集

- 不做锄地、播种、浇水、生长、收获或作物。
- 不做工具栏、完整背包、物品堆叠或制作。
- 不做砍树、碎石、资源掉落或环境破坏持久化。
- 不做金币、商店、买卖、价格或经济。

树和石头只提供视觉层次、遮挡与碰撞。

### 9. 不做人物与内容量

- 不做 NPC、对白、好感、日程、任务、事件或恋爱。
- 不做小镇、矿洞、多个农场、程序生成或地图选择。
- 不做战斗、等级、装备、钓鱼、节日、天气和季节。

首片只有玩家角色、农场和住宅室内。

### 10. 不做复杂时间与生存数值

- 不做实时钟表、昼夜光照、体力、饥饿、睡眠惩罚或昏倒。
- 不做复杂日历、多个存档槽、回滚、云备份或旧 FableSpace 存档迁移。

允许显示 `第 N 天`，并在床边交互完成一次原子的 N 到 N+1。

允许把当前农场游戏的合法 `farm-game.save.v1` 补齐名字与外观后迁移为 v2；不得扫描或迁移任何其他旧产品键。

### 11. 不做额外平台

首片不做移动端触控、虚拟摇杆、移动端专用布局、手柄、桌面客户端、离线 PWA 或多人。浏览器尺寸变化仍须保持画面可见、等比且像素清晰。

### 12. 不用假能力掩盖状态

- 资源加载失败时不显示空白 canvas 或伪造已加载场景。
- 本地存档损坏时不猜字段、不采用旧 FableSpace 数据；明确回到新游戏。
- 不用假日期、NPC、统计、背包或未实现按钮装饰页面。
- 不用说明长文替代可见场景、操作反馈和简短错误状态。

## 快速判断

方向正确的需求会强化移动手感、碰撞、遮挡、场景切换、睡眠单次结算、本地恢复、像素清晰度或素材可追踪性。

需要停止并回到合同审查的需求通常要求恢复旧故事平台，引入 LLM/API/数据库/SSO，把论坛变成门槛，建设现实地图/LBS，复制商业游戏表达，或把首片扩成完整农场经营系统。
