# Godot 农场手册界面

本批延续清新田园方向，改造 `apps/mirror-island/godot/ui/` 的现有原生界面。玩法世界是主要画面；HUD 分居两角，底部保留十二格活动工具行，打开菜单时使用暖白手册与林绿遮罩。

- 暖白 `#fff9eb` 承载文字，深林绿 `#274d40` 用于主操作与选中态，鼠尾草 `#dce8d5` 表示信息分组，蜜金 `#bd8b42` 用于金币、刻度和局部细节。
- 中文沿用已锁定的 Noto Sans CJK SC。普通标题 22–26，启动标题 30–40，正文 16，次级文字 12–14；窄屏优先重排和滚动，不整体缩小文字。
- 标题、滚动内容和底部提示分开。原生按钮保留鼠标、键盘和触摸语义，焦点与选中是不同状态。
- 背包、配方、居民、技能和日历使用真实快照；价格、数量、物品品质、库存目标格、命令和存档格式保持原合同。
- 动效仅用于打开手册的 0.16 秒淡入，不移动命中区域，也不在持续刷新的快照上重复播放。
- 字体和第三方依赖沿用现有版本。基础工具已采用此前制作并于本次正式上传登记的 PNG 图集；没有新制图片。旧 `DESIGN.md` 中网页启动页规则属于历史视觉资料，本批以本文和 Godot 实现为准。

验收关注桌面与窄屏布局、工具栏、背包选择与拖放、制作目标格、菜单互通、长文本、键盘焦点和保存失败提示。自动解析、构建与截图不能代替真人连续游玩和真实存档恢复验收。
