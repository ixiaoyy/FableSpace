# 单管理员 StoryWorld 内容后台

## Goal

为 FableSpace 增加一个单管理员内容后台，使 StoryWorld 的世界设置、背景设定、章节和 Character 不再只能通过修改代码维护。管理员从故事世界列表进入具体世界，在四个独立页面中编辑；保存后公开 Character 页面和故事运行时立即读取最新内容。

## Background

- 当前 StoryWorld 内容由 Python 冻结 dataclass 和 `StoryWorldRegistry` 固定加载。
- 当前没有内容管理页面或管理 API。
- 现有登录会话可提供可信账号 ID，后端已有 SQLAlchemy 与 S3 兼容存储配置。
- 首页内容配置和独立媒体库本期不做；公开首页继续使用现有实现。

## Requirements

### 信息架构

- 全局侧栏首版只保留“故事世界”。
- “故事世界”首页展示世界列表，点击世界后进入该世界。
- 世界内固定分为“世界设置、背景设定、章节管理、角色管理”四个页面，不把不同内容混在同一棵树或同一表单中。
- 页面使用固定响应式布局和显式字段，不提供拖拽搭建、主题、样式或通用 JSON 编辑器。
- 界面不放需求说明、设计解释或教学型文案。

### 管理范围

- 世界设置可编辑 StoryWorld 标题、摘要、题材和当前入口。
- 背景设定可编辑分层正史与剧情背景条目。
- 章节管理可新增、编辑、排序和删除章节，并管理节点、旁白、选择、关系影响和结局目标。
- 角色管理可新增、编辑、排序和删除 Character，并编辑动机、语言、边界、初始关系及关系规则。
- Character 始终属于 StoryWorld，不成为通用角色卡。
- 现有 PlayerRole 与结局数据必须完整往返保存，但首版不提供独立编辑页面。
- 后台不展示或修改玩家对话、关系、记忆和进度。

### 保存与运行

- 管理内容持久化到数据库；Python 注册表只作为首次引导来源。
- 保存即生效，不设草稿、提交、审核、发布、回滚或人工版本选择。
- 新 StoryRun 和活动 StoryRun 的后续请求始终读取最新 StoryWorld 内容。
- 活动轮次引用已删除内容时，保留历史记录、停止旧轮次，并从当前有效入口重新开始；无法构造有效入口时返回受控内容错误。
- 保存时校验必填字段、唯一 ID、同世界引用、Character/PlayerRole 跨世界唯一性和剧情图闭合。

### 管理权限

- 后台只供部署环境配置的一个固定管理员账号使用。
- 服务端以现有可信会话账号 ID 与管理员 ID 比较，保护全部管理 API。
- 未配置管理员 ID、未登录或账号不匹配时拒绝访问。
- 不新增独立后台密码，不把管理员 ID 或对象存储凭据下发前端。

### 角色图片

- 角色编辑页可直接上传管理员自己的 PNG、JPEG 或 WebP 图片到项目现有 S3 兼容存储桶。
- 不建设媒体库页面、资产列表或通用素材选择器。
- 首版不裁剪、不缩放、不转码；校验文件类型、大小、空文件和真实图片头。
- 每次上传生成新的不可变对象 key，禁止覆盖和删除。
- 后端记录对象 key、HTTPS URL、字节数、SHA-256、MIME、可获得的宽高、`user-provided` 来源和来源说明。
- 上传成功后直接写入当前 Character 的图片 URL，存储凭据不经过浏览器。

## Acceptance Criteria

- [ ] 全局侧栏首版仅显示“故事世界”，不显示媒体库或首页内容。
- [ ] 管理员可在世界列表中切换不同 StoryWorld，并进入四个相互独立的管理页面。
- [ ] 未配置管理员 ID、未登录或账号不匹配时，所有管理 API 均拒绝访问。
- [ ] 管理员可编辑并保存世界设置、背景设定、章节和 Character。
- [ ] Character 编辑页可上传 PNG、JPEG、WebP，并保存不可变 HTTPS 图片 URL。
- [ ] 修改 StoryWorld 内容后，新的运行时请求立即使用最新保存内容。
- [ ] 活动轮次引用已删除内容时不会删除历史或产生未处理服务器错误。
- [ ] 初始安妮与长明宫内容被幂等引导到数据库，已有管理内容不会被覆盖。
- [ ] 保存拒绝缺失必填字段、重复 ID、跨世界引用和断裂剧情图。
- [ ] 权威产品、Schema、图片与部署文档同步到单管理员和数据库内容合同。

## Out of Scope

- 首页内容配置、首页角色排序和首页图片管理。
- 独立媒体库、资产浏览、资产选择、资产删除和批量上传。
- StoryWorld 创建/删除、PlayerRole 独立编辑页和通用结局管理页。
- 多管理员、权限角色、操作审计、草稿、审核、发布、回滚和内容版本兼容。
- 页面搭建器、拖拽布局、主题与任意样式编辑。
- 图片裁剪、缩放、转码、自动抠图和 AI 生图。
- 用户创作、店主后台、创作者市场、SillyTavern 角色卡和玩家数据运营后台。
- LLM Key、模型、Token 计费和 StoryWorld 私有模型配置。
