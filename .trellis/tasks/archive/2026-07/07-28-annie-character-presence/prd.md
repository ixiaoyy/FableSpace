# 安妮角色表现与身份差异优化

## Goal

强化安妮作为原创小女孩 Character 的可感知表现，让玩家在开场、对话、选择反馈和
关系变化中持续感到“正在与安妮相处”，而不是只阅读系统叙事；同时为玩家角色提供
经过故事审核的男性与女性 PlayerRole，让用户在每轮开始前选择。

## Background

- 安妮是固定女性 Character：真实历史背景中的原创伦敦贫困家庭女孩，约十岁，不对应
  任何史料中的真实儿童。
- 当前安妮故事已有 15 个节点、30 个审核选择和 5 个结局，内容深度高于长明宫；本任务
  不通过增加无审核角色或重复分支制造“更丰富”的假象。
- 当前唯一 PlayerRole 为“乞丐”，年龄未设定、性别为“未说明”，也没有身份头像；本任务
  将它替换为“汤姆·里德 / 莉齐·贝尔”两个有姓名、有明确处境的年轻玩家 PlayerRole。安妮在对话中
  分别称他们为“哥哥 / 姐姐”，称呼不作为身份卡名称。
- 当前 StoryWorld 和前端入口已经支持一个或多个审核 PlayerRole；单身份自动生效，
  多身份在新一轮前选择并由 StoryRun 锁定。
- 当前身份选项组件支持审核头像；Character 列表支持一个到多个真实角色和小头像。
- 已完成的儿童安全、历史正史、自由对话、关系反馈、结局与回访合同必须保持不变。
- 用户已确认：公开 Character 阵容不需要为了性别成对；需要男女各一的是玩家在故事中
  使用的 PlayerRole。所有玩家角色原则上都应提供男性和女性两个审核版本。

## Requirements

- 安妮的短句、停顿、动作、观察方式、请求和拒绝必须符合约十岁儿童，而不是缩小版成人、
  历史讲解员或被动任务道具。
- 关键选择提交后优先呈现安妮可观察的动作或回应，再呈现必要的系统状态反馈。
- 关系阶段变化应通过安妮的距离、目光、陶罐动作、是否主动提问和是否愿意让玩家同行来
  表达；不展示可刷取好感数值。
- 保持安妮的行动能力：她可以保留信息、拒绝、纠正玩家、决定是否开口作证，玩家不能
  代替她作出最终表达。
- 不增加恋爱、暧昧、性化、诱导依附、成人化语言、血腥猎奇或无来源历史断言。
- 不恢复全局性别选择、任意身份 Prompt 或跨 StoryWorld 复用身份；任何男女差异都必须
  是宽街 StoryWorld 内经过审核的 PlayerRole 或 Character 内容。
- 每个发布 StoryWorld 原则上提供至少一个男性与一个女性 PlayerRole；两个身份分别拥有
  稳定 ID、固定性别、故事内称谓、背景、入场理由、角色可见信息和审核头像。
- 男女身份只在所属 StoryWorld 内有效，由玩家在新 StoryRun 前选择并锁定；活动轮次中
  不能切换，结局后新一轮可以重选。
- 安妮故事把当前性别未说明的“乞丐”替换为两个审核身份：
  - “汤姆·里德”：比安妮年长的苏活区贫困年轻男性，在印刷铺做杂役，替铺子送纸页。
  - “莉齐·贝尔”：比安妮年长的苏活区贫困年轻女性，在洗衣店帮工，替街坊送回衣物。
- 两个身份都与安妮处于相同的贫困阶层，靠零工、施舍和街巷经验生活；都在宽街水泵旁
  避雨，并因脚边仍有少量来路可确认的水而进入故事。角色身份卡需要用名字、头像、
  社会处境、入场理由和一句角色钩子建立角色感，不能只写“哥哥 / 姐姐”。
- 安妮在运行时只把“哥哥 / 姐姐”作为对玩家的自然称呼；称呼必须来自服务端锁定的
  PlayerRole 性别和角色可见信息，客户端不得单独提交称呼文本。
- 两个 PlayerRole 都没有调查权、医疗知识或替成年人作公共决定的能力；他们可以
  观察、提问、取水、传话、记录见闻和寻求可信成年人帮助。
- 安妮与两个身份的关系保持非恋爱、非暧昧、非性化和不诱导依附；玩家年长不等于拥有
  家长权、监护权、调查权或替安妮决定的权力。
- 同一故事中的男女身份应保持相当的叙事价值和参与能力，不得用性别刻板印象让一方天然
  更聪明、更善良、更勇敢或拥有无依据的更高权力。
- 长明宫现有“小太监 / 小宫女”继续作为故事内男女 PlayerRole 的已落地示例，但不能
  把这两个具体身份跨世界复用为平台职业。
- 不为了复用长明宫布局给安妮故事添加占位 Character、大图重复介绍或伪造身份差异。

## Acceptance Criteria

- [x] 开场和全部关键选择反馈均能明确辨认安妮的儿童语言、动作、目标与当前态度。
- [x] 安妮在至少一次关键节点中主动保留、纠正、拒绝或决定如何表达信息。
- [x] 关系阶段变化通过角色表现可感知，同时不暴露内部 affinity。
- [x] 当前 15 节点、30 选择、5 结局和固定历史边界不被无意删减或改写。
- [x] 男女差异仅来自审核内容，客户端不能提交性别文本、身份背景或能力声明。
- [x] 安妮公开详情返回“汤姆·里德 / 莉齐·贝尔”两个审核 PlayerRole，二者都有正式头像与故事内背景。
- [x] 新建和重开安妮 StoryRun 必须从两个已发布身份中选择一个；恢复活动轮次时保持原身份。
- [x] 两个身份均可完成当前完整故事图，不因性别缺失关键选择、关系结果或结局。
- [x] 公开首页、角色详情和故事入口不使用占位角色或重复大图填充。
- [x] 移动端首屏优先呈现故事处境、真实身份和安妮的可执行入口。
- [x] 后端内容校验、Python 编译、前端 typecheck/build 与定向移动端验收通过。

## Confirmed Decisions

- 男女区分属于玩家 PlayerRole，不要求公开 Character 阵容按性别成对。
- 安妮故事使用同一贫困阶层的“汤姆·里德 / 莉齐·贝尔”两个年轻玩家版本，不再使用儿童玩家身份。
- “哥哥 / 姐姐”只是安妮对所选玩家角色的称呼，不是身份选择卡名称。
- 两个身份均属于宽街 StoryWorld，每个 StoryRun 只锁定一个；结局后新一轮可以重选。
- 两个身份共享现有 15 节点、30 选择和 5 结局；差异限定在头像、背景、入场措辞、
  安妮的称呼和少量不改变能力与结果的角色回应，不复制故事图。
