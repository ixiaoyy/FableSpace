# 安妮宽街完整故事迁移设计

## 1. 边界

本任务只重写
`apps/api/src/fablespace_api/content/annie_broad_street.py` 中的系统内容。
`StoryWorld`、`StoryNode`、`StoryChoice`、运行时 API 和数据库结构保持不变。
旧 `_historical_broad_street_gameplay()` 仅提供已经审阅的场景、选择和终局
文字来源；新实现不 import、不调用也不适配旧 Gameplay。

## 2. 剧情图

新图保留一个章节和五个终局，入口扩展为五类明确动作：

```text
讨水
├─ 说明来路并分享水 -> 核对来路
├─ 追问水泵         -> 水泵与街坊
├─ 陪她另找水       -> 绕开水泵
├─ 求助询问者       -> 死亡登记名单与取水来源
└─ 拒绝介入         -> 疏远结局

核对来路 / 水泵与街坊 / 绕开水泵 / 询问者
  -> 逐户证词 / 对照取水来源 / 核对纸页
  -> 由谁开口
  -> 信任 / 并肩 / 修复 / 戒备 / 疏远
```

目标不少于 15 个节点。循环只用于回到仍可选择的调查节点；所有节点都必须
从入口可达，五个 `StoryEnding` 都必须被终局节点引用。

## 3. 关系设计

关系阶段调整为：

| 阶段 | 最低 affinity | 玩家可见含义 |
|---|---:|---|
| `guarded` | -20 | 安妮收回纸页，只说眼前能确认的事 |
| `watchful` | 0 | 她愿意听，但仍在核对玩家是否诚实 |
| `walking_together` | 4 | 她允许玩家同行并共同核对线索 |
| `trusting` | 10 | 她相信玩家会尊重事实和自己的发言权 |

普通调查选择以 `+1` / `+2` 为主；最终尊重安妮发言权的选择可以产生
`+3` / `+4`。危险保证、伪造证据和抢夺叙述权产生 `-3` 至 `-5`。运行时
继续负责按上下界截断，内容层只提供确定性原因和关系标记。

## 4. 历史内容

沿用已审阅的史实底稿：

- 1854 年 8 月 31 日夜至 9 月 1 日暴发显著加剧；
- Snow 使用死亡登记资料并逐户核对饮水来源；
- 9 月 7 日晚向 St James 教区监护委员会陈述，次日移除泵柄；
- Snow 自述泵柄移除前暴发已经开始减退；
- 济贫院与啤酒厂只作为取水来源对照，不推导“酒能防病”；
- 点图不是 Snow 首次提出水传播假设的起点。

安妮、她的家庭、陶罐、玩家同行、纸页和五个私人结局全部保持
`story_setting`。终局叙事重复必要的固定公共结果，避免某条分支暗示玩家
改变历史。

## 5. 版本与兼容

提升 `content_version`，不迁移或改写已有 StoryRun。当前运行时仍按锁定的
版本字段持久化，但投影时仍从现行注册表按节点和结局 ID 解析。为避免已有
轮次直接失效，本内容保留现行切片的三个终局节点 ID 和三个结局 ID；本任务
不增加旧版本解析器，也不修改数据库。真正按 `content_version` 读取历史
内容由后续运行时任务负责。

## 6. 验证

任务内验证脚本只加载系统内容并检查：

- 节点、选择、终局计数；
- 五类入口存在；
- 五个结局可达；
- 关系阶段阈值与单次变化范围；
- 每个终局包含固定公共历史边界；
- published 内容没有 `needs_verification`；
- 旧 Space 文件无本任务 diff。

随后运行项目规定的 Python 最小检查，并记录历史对抗式自审 Verdict。

## 7. 回滚

唯一生产回滚点是
`apps/api/src/fablespace_api/content/annie_broad_street.py` 的本任务差异。
若内容引用、史实审查或编译失败，只精确撤销本任务在该文件的修改，不触碰
工作区已有改动或旧 Space 内容。
