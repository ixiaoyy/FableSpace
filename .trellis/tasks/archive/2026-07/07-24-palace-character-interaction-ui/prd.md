# 完成长明宫双角色故事交互界面

## Goal

把长明宫角色故事入口改造成可直接进入剧情的开场决策页：玩家先理解当前局势，从系统审核的“小太监 / 小宫女”中选择本轮 PlayerRole，再从真实角色列表选择魏观海或萧明珠开始对话；活动轮次恢复、关系反馈、选择与结局继续使用同一 StoryWorld 运行时。

## Background

- 首页已经承担角色大图与角色介绍，故事入口不得重复大图角色详情。
- 角色数量是数据规模，不是页面结构；入口列表必须支持一个到多个真实 Character。
- 2026-07-28 用户确认长明宫提供两个经过系统策划的 PlayerRole，并确认身份按本轮 StoryRun 锁定。
- 当前代码和权威文档仍使用每个 StoryWorld 恰好一个固定 PlayerRole，需要同步升级为一个或多个系统预设身份；安妮 P0 仍只有“乞丐”一个身份并自动生效。

## Requirements

- StoryWorld 系统内容支持一个或多个同世界 PlayerRole，禁止空列表、跨世界引用、重复 ID 和任意客户端身份 Prompt。
- 长明宫发布两个审核身份：
  - “小太监”：成年低阶内侍，能传令、跑腿和查证，无开门、宣诏或替上位者决策的权力。
  - “小宫女”：成年低阶宫女，能递话、送物和查证，无进入禁地、传旨或替上位者决策的权力。
- 两个身份各有经过人工确认的原创头像；正式引用必须使用对象存储 HTTPS URL、不可变 key、manifest 和 prompt sidecar。
- 公开角色详情返回全部可选 PlayerRole；只有一个身份时保持自动生效，不增加必经选择步骤。
- 新 StoryRun 和重新开始请求只接受当前 StoryWorld 发布的 `player_role_id`；服务端验证并把选择锁定到 StoryRun，客户端不能提交任意角色文本、能力或玩家 ID。
- 活动轮次恢复时使用已锁定 PlayerRole，不重新询问或允许中途更换；结局后开始新轮次时可以重新选择。
- 对话 Prompt 必须使用 StoryRun 锁定的 PlayerRole，而不是 StoryWorld 的默认或客户端临时状态。
- 故事入口首屏只展示故事处境、身份选择和紧凑 Character 列表；角色项使用小头像、姓名、当前状态和位置，不重复首页的大图介绍。
- Character 列表由真实数据生成，支持一个到多个角色；不得用占位角色、固定双列结构或说明性填充文案。
- 魏观海、萧明珠共享同一长明宫 StoryRun 中央事件，但对白、关系、选择反馈和可见秘密来自各自真实 Character 投影。
- 支持活动轮次恢复、人工选择、自由回应、关系阶段、最近变化原因、结局和重新开始。
- 不显示 affinity，不允许关键选择回退，不用安妮文本、旧 Space 聊天或假数据兜底。
- 移动端优先；身份二选一、角色列表、输入、选择、关系与结局在窄屏保持完整，新增动效尊重 reduced motion。

## Acceptance Criteria

- [x] StoryWorldRegistry 接受单身份与多身份世界，并拒绝空、重复、跨世界或字段非法的 PlayerRole。
- [x] 长明宫公开详情返回小太监、小宫女两个审核身份及各自头像；安妮仍返回单个乞丐身份。
- [x] 新建和重开 StoryRun 必须提交有效 `player_role_id`，选择持久化到 StoryRun 并在运行响应中回显公开投影。
- [x] 活动轮次刷新或从魏观海 / 萧明珠入口恢复时保持同一个已锁定身份，不能中途切换。
- [x] 对话系统上下文使用当前 StoryRun 的身份设定；无效或跨世界身份被服务端拒绝且不创建状态。
- [x] 魏观海、萧明珠均可从各自 Character 深链进入同一长明宫故事，角色列表不会把数量硬编码为两个。
- [x] 首页角色大图不在故事入口重复；桌面和 `390×844` 布局能看到故事处境、两个身份和真实角色入口。
- [x] 两枚采用头像已上传到 `fablespace/media/v1/`、写入 manifest 与 sidecar，本轮没有向 Git 添加图片二进制。
- [x] 写操作有明确加载、失败和会话失效状态，不乐观伪造成功。
- [x] 结局前不可回退关键选择，结局后可重新选择身份并开始新轮次。
- [x] 权威产品与 Schema 文档、API 类型、SQL migration、后端编译、前端 typecheck/build 和移动端视觉验收全部通过。

## Out of Scope

- 全平台身份目录、用户自定义身份 Prompt、账号性别或跨 StoryWorld 职业。
- 为安妮故事增加多身份选择。
- 修改长明宫已审核中央事件、章节图、角色动机或结局。
- 恢复旧 `Space`、`play_identity_id` 或 `VisitorState` 兼容合同。
