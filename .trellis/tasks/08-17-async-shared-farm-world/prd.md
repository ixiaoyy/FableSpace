# 规划镜像岛共享世界

## Goal

以 RPGJS v5 开源项目为新底座，重建一个 512×512 瓦片的共享“镜像岛”：登录玩家能看到同区块其他玩家小人，在完全无主的公共土地上共同耕作和争抢收获，并由固定 NPC 免费帮助玩家在自选位置建造一座私人住宅。

## Background

- 当前公开游戏是 React + Phaser 纯前端原型，角色和进度只在 localStorage；当前已暂存的湖畔代码尚未提交。
- 用户明确决定停止继续扩展现有自研运行时，不要求保留 Phaser/FastAPI 游戏实现，优先整体复用成熟开源项目。
- Kaetram 功能接近但附加 OPL 限制 AI 相关用途，当前 AI 协作项目不能安全采用；RPGJS 为 MIT 的 TypeScript 浏览器 RPG/MMORPG 引擎，已提供地图房间、玩家同步、动态 tile、NPC/Event、物品/背包、认证钩子和存档策略。
- 真正共享的世界状态必须由服务端权威处理；玩家少只降低容量，不消除认证、并发、持久化、迁移和回滚要求。

## Requirements

### 开源底座与切换

- 新应用以 `@rpgjs/server`/`@rpgjs/client` `5.0.0-beta.32` 为首个固定评估版本，上游提交固定为 `7c7db1b51e6f9deea8c33926f729c013a39340a6`，许可证 MIT。
- RPGJS 负责地图房间、玩家小人同步、NPC/Event、动态 map/tile、物品/背包和玩家存档接口；项目只编写镜像岛专用规则与必要适配。
- 新 RPGJS 应用先与当前原型并行运行；纵向切片通过后再切换 `/` 和部署，随后精确清退旧 React/Phaser 游戏代码。未经切换验收不直接覆盖可运行版本。
- 正式采用的开源依赖必须锁定版本/提交，记录许可证、维护状态、采用范围和退出路径。

### 登录与注册

- 不提供游客模式；未登录只能进入登录/注册界面，认证成功后才连接 RPGJS 世界房间。
- 支持两种互斥注册方式：当前论坛账号，或独立用户名+密码。角色显示名与登录用户名分离。
- 从已登录论坛进入：已注册游戏账号则直接登录；未注册则进入注册页，可选择用当前论坛身份注册或改用独立账号注册。
- 独立账号不要求邮箱、验证码或找回密码；密码允许 1–72 个字符，包括 `123`，不要求复杂度。空密码拒绝。
- 首版不支持论坛身份与独立账号后续绑定、合并、解绑或农场迁移。
- 使用 Keycloak 开源身份服务管理独立账号、Remember Me 和会话；论坛现有 SSO 通过最小身份桥接进入 Keycloak。RPGJS `auth()` 只接受 Keycloak 验证后的稳定 subject。
- 登录凭证不进入 localStorage；浏览器依赖 Keycloak 安全会话，RPGJS access token 只保存在内存并按官方客户端刷新。

### 世界与玩家

- 世界名称为“镜像岛”，首发固定 512×512 个 16px 瓦片，拆为 16×16 个 32×32 瓦片区块/地图房间。
- `simplex-noise` 4.0.3（MIT）和固定 seed 生成树林、水域、道路、可耕地与公共起点；同一 world revision 在所有客户端生成一致基础地形。
- 玩家只加载/连接当前位置相关区块；跨区由 RPGJS 房间切换处理，不一次性渲染整张世界。
- 使用 RPGJS 内置 WebSocket 同步同区块玩家小人、移动和动态世界状态；不自研玩家同步或 5 秒轮询。
- 首版不增加玩家碰撞、聊天、交易、组队或共同权限系统。

### 公共耕作与争抢

- 没有私人农场、土地认领、作物 owner、占地上限或土地回收；土地和作物始终无主。
- 任意登录玩家可锄地、播种、浇水、清理和收获任何共享格；服务端校验当前状态版本并原子接受合法转移。
- 两人同时操作同一格时只接受一个状态转移；两人同时收获时只有一个成功，土豆进入第一个成功账号的 RPGJS 个人背包。
- 首版作物为春季土豆：无限种子、鼠标热栏、3 次有效浇水跨日成熟；春转夏时所有在地土豆枯萎，任何人可清理。

### 全服时间

- 世界年份、季节、日期和时间由服务端固定 epoch 统一推导；每季 28 天，现实 7 秒推进游戏 10 分钟，6:00 到次日 2:00 后统一进入下一天 6:00。
- 所有客户端显示同一世界时间；单个玩家睡觉不能推进日期。
- 服务器在全服 2:00 边界只结算一次作物生长和跨季；在线玩家刷新权威结果。
- 床只结束本次游玩/返回入口，不改变世界时间。

### NPC 与私人住宅

- 新账号首次从固定公共起点进入；确定性 NPC 欢迎玩家来到“镜像岛”，不使用 LLM 或自由对话。
- NPC 免费帮助建造第一座住宅；玩家没有建造系统、材料成本、配方或建造工具，只负责在世界中移动并放置一次房屋选址标记。
- 服务端原子校验地形、道路、水域、动态格和其他住宅 footprint；确认后 NPC 立即完成房屋，不等待次日。
- 每个账号首版最多一座住宅。住宅建筑绑定建造者账号，室内是 RPGJS 私人实例；其他玩家只看外观和建造者名称，不能进入、拆除或修改。
- 住宅周围土地仍完全无主；已建房玩家在全服 2:00 回到住宅，未建房玩家回公共起点。正常登录恢复上次安全位置。

### 旧档与个人数据

- 首次注册时只从合法旧 localStorage 存档预填 `player_name` 和 `avatar_id`，用户确认后写账号资料。
- 不迁移个人 day/time/scene/spawn、旧住宅或本地耕作状态；共享时间、位置、住宅和格子以新服务器为准。
- 旧 localStorage 暂时保留为只读回退副本，不再更新。

## Acceptance Criteria

- [ ] RPGJS 固定版本纵向切片能显示两名已认证玩家小人、同房间移动、NPC、物品背包和动态 tile；旧原型仍可回滚。
- [ ] 未登录不能进入世界；论坛注册与独立用户名密码都产生稳定账号会话，Remember Me 后再次进入直接登录。
- [ ] `123` 可注册，空或超过 72 字符密码被拒；浏览器与日志无明文密码或持久化 access token。
- [ ] 512×512 固定 seed 世界按 32×32 房间稳定生成，跨区只加载相关地图，相同 revision 地形一致。
- [ ] 同区块玩家小人和共享格子通过 RPGJS 原生 WebSocket 同步，不存在自研轮询协议。
- [ ] 土地和作物无 owner；任意玩家可照料/争抢，竞态下同一动作或收获只结算一次。
- [ ] 全服时间、28 天四季、土豆三次生长和春转夏枯萎只由服务器结算一次，个人睡觉不能推进。
- [ ] NPC 欢迎新玩家并在合法选址后立即免费建一座私人住宅；重叠房屋并发只能一个成功，周围土地仍公共。
- [ ] 其他玩家只能看住宅外观，建造者能进入私有室内；2:00 与重新登录位置规则正确。
- [ ] 旧本地存档只迁移名称和外观，其余个人状态不进入共享世界。
- [ ] 所有开源依赖有许可证/版本/采用边界记录；数据库迁移在用户批准表结构前不存在。

## Out of Scope

- 自研游戏引擎、地图房间、玩家同步、通用背包或账号平台。
- 土地/作物所有权、私人农场边界、土地交易、作物保护或收获归属保护。
- 玩家碰撞、聊天、交易、组队、好友、排行榜或公共住宅室内。
- 邮箱、验证码、找回密码、账号绑定/合并、游客模式或多个住宅。
- 无限世界、现实地图、LBS、运行时改 seed 或未评审的数据库迁移。
