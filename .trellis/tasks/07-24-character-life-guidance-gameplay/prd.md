# 角色人生抉择与成长玩法

## Goal

为 FableSpace 增加 Character 个人成长故事：玩家通过固定 PlayerRole 与 Character 对话、查证并承担行动风险，影响 Character 作决定时掌握的信息和对玩家的信任；Character 保留最终决定权，并在后续故事中延续与玩家的长期关系。

首个可玩切片位于原创架空 StoryWorld“长明宫”，以新 Character 林晚照（林才人）的第一章为验证内容，不触达皇后、冷宫或任何最终结局。

## Background

- StoryWorld 继续承载稳定正史、世界规则、固定 PlayerRole 和 Character；公开发现仍然以 Character 为入口。
- 同一 StoryWorld 可以包含两种审核故事形态，但两者必须复用同一套 StoryRun、章节、选择、事件和状态写回机制：
  - 群像故事：以公共事件为中心，多名 Character 共享本故事的进度与结局；“雪夜封宫”属于此类。
  - 个人成长故事：以一名焦点 Character 的变化为中心，其他 Character 作为盟友、阻力、导师或对照出现；林晚照的故事属于此类。
- Character 详情页以文学化栏目名“命途 / 世事”呈现两类故事，不显示“个人成长故事 / 群像故事”等解释性分类文案。
- “雪夜封宫”保持原有中央事件、角色设定和独立 StoryRun；林晚照的故事不覆盖、改写或伪装成其内容版本。
- 不同故事共享同一玩家与同一 Character 的长期关系；各自的进度、剧情标记、关键选择、局部状态和结局相互隔离。
- 当前权威合同只允许一个 StoryWorld 入口章节、每个玩家与 StoryWorld 只有一个活动轮次指针，CharacterRelationship 也只属于单个 StoryRun。实现前必须显式更新产品与 Schema 合同，不能用 `content_version`、旧 GameplayDefinition 或兼容适配器绕过。
- 当前新 StoryWorld 内容注册表仅包含安妮宽街故事；长明宫新合同内容由既有“重写雪夜封宫故事”任务提供，本任务不能以 `core/default_spaces.py` 的旧 Space 内容作为新实现基线。

## Product Requirements

### 故事与状态边界

- 每个审核故事拥有稳定 `story_id`、故事类型、参与 Character、焦点 Character（个人成长故事必需）、入口章节和独立 StoryRun。
- StoryRun 必须锁定 `story_world_id + story_id + content_version`；开始、恢复、消息、选择和重开都必须校验同一故事范围。
- 同一玩家可以在同一 StoryWorld 的不同故事中分别保留未完成进度；切换 Character 或故事不能覆盖另一个故事的活动轮次。
- 长期 CharacterRelationship 按玩家、StoryWorld 和 Character 定位，供同世界故事共享。
- 首个可玩切片只共享关系阶段、当前态度和最近变化原因。带来源、可见性和去重规则的跨故事关系里程碑延期。
- 重玩故事不能反复刷取长期关系收益。

### Character 对话与跨角色拜访

- 一次对话只发生在玩家主动进入的单个 Character 页面；其他 Character 不得为了推进剧情自动出现在当前页面。
- 多 Character 故事通过玩家分别拜访不同 Character 推进。各 Character 读取同一 StoryRun 中自己允许观察的事件，并从自身立场回应。
- 当前 Character 可以通过自然对白、物件或线索指出另一名 Character 可能知道什么。
- 当对白明确引出另一名可拜访 Character 时，页面可以显示低调、可点击的角色头像入口；不显示“下一任务”等任务式文案，不自动跳转。
- 玩家是否离开、去见谁、是否带回线索，以及向下一名 Character 透露什么，均由玩家主动决定。

### Character 自主决定

- 玩家表达的是建议、立场或自己愿意执行的行动，不能直接指定 Character 的最终决定。
- 玩家可以在固定 PlayerRole 能力边界内送信、查证、隐瞒、作证、求援或拒绝协助；每项行动必须有可理解的风险、机会成本或关系代价。
- Character 根据人格、核心价值、弱点、已知信息、长期关系和本故事既往行为，选择采纳、拒绝、误解或部分执行玩家建议。
- Character 作出决定后，必须用可观察且符合角色语言的反应说明影响为何生效或未生效。
- 自由对话可以产生受限关系反馈，但不能推进关键状态、创建永久结果或绕过审核选择。

### 完整成长故事愿景

- 完整故事由 4–6 个因果相连的审核章节组成，可跨回访恢复同一 StoryRun。
- 各章发生在同一场连续数周的宫廷危机中，不使用跨年时间跳跃或明显年龄变化。
- 中央事件为后位空悬、三十日内必须册立新后。强势家族相互否决，使低位且暂未归属任何一派的林晚照成为潜在折中人选。
- Character 成长采用两条独立叙事结果轴：
  - 外部处境：身份、地位、权力、安全和可用机会。
  - 内在成长：判断力、勇气、自主性、信任方式、价值取向和行为风格。
- 成为皇后可以伴随内在异化与关系破裂；进入冷宫也可以伴随原则、自主性或关系成长。前台不展示成长分数、好感数值、最佳结局或统一胜负标签。

## First Playable Slice

### Character

- 姓名：林晚照。
- 当前称谓：林才人。
- 表层行为：安静谨慎，习惯降低存在感。
- 核心能力：善于观察人情、权力流向、债务与谎言。
- 核心价值：不愿轻易牺牲真心信任自己的人。
- 致命弱点：恐惧时拖延决定，默许更弱者先承担代价，并以“活下来才有以后”合理化退缩。
- 初始目标是在宫中自保并保护贴身宫女，不以争夺后位作为开场任务。
- 对白克制、含蓄；戒备时常用假设和反问试探，建立信任后才更多直接使用“我”，被逼到绝境时语言更短、更明确。
- 玩家曾按“小太监”职责替其宫院送炭、药材或口信，双方相识但尚未真正信任。无长期关系记录时使用“相识但戒备”的审核基线。

### 第一章：封口之信

- 林晚照的贴身宫女被搜出一封未送达的违禁家书。
- 家书暗示林晚照的父亲可能卷入朝廷亏空案，且封口有被人动过的痕迹；亏空与宫中账目相关。
- 家书来源、封口异常、宫女责任和查证路径必须有预先审核的确定答案，不能由运行时 AI 决定真相。
- 林晚照先以试探发问：“若一封信从未到过收信人手里，它还能算那个人的罪证吗？”
- 玩家可以自由对话，并决定是否查验封印、隐瞒发现或主动去见魏观海。
- 林晚照用自然对白指出司礼监封口暗纹，页面随后可以显示可选的魏观海头像入口。
- 魏观海不是设局者，也不知道完整幕后真相。他认得封口暗纹来自一批已经停用的司礼监旧札，并知道哪些人有机会接触旧札。
- 魏观海先观察玩家是否泄露林晚照的私话、是否急于站队，再按长期关系和本次言行决定线索深度：
  - 信任且谨慎：指出可查证的旧札接触路径。
  - 关系普通：只确认封口有假。
  - 冒失或泄密：扣下线索，并把玩家与林晚照列为观察对象。
- 玩家主动回到林晚照页面，给出建议，并说明自己愿意承担的行动。
- 林晚照结合证据、人格、关系和既往行为作出第一次自主决定。玩家不能直接选择结果：
  - 认下家书：保护宫女，自己被禁足候查，玩家获得信任但后位机会受损。
  - 否认知情：宫女被带走，林晚照暂时安全，并强化以他人代价换取自保的倾向。
  - 请求复核：利用封口疑点拖延处置，主仆暂留，但玩家与林晚照进入魏观海的观察名单。
- 三个结果均进入“三日后复核”的未完成状态，只写回第一章局部状态、长期关系与内在成长依据；StoryRun 保持活动，不生成临时结局或完成摘要。

### Preview Boundary

- 首个可玩切片只用于未发布内部草案/预览。
- 完整故事、内容评审、角色图片资产与发布验收完成前，林晚照及其“命途”不得进入公开首页发现或普通玩家运行时。
- 预览能力必须默认关闭且不能依赖数据库手工改值、伪造公开数据或旧 Space 入口。

## Acceptance Criteria

- [ ] 同一长明宫内容中，“雪夜封宫”与“封口之信”拥有不同 `story_id`、独立进度和独立结局边界。
- [ ] Character 详情以“命途 / 世事”呈现审核故事，不包含解释内部分类的文案。
- [ ] 同一玩家可分别恢复同世界不同故事的活动 StoryRun，切换故事不会覆盖另一故事进度。
- [ ] 同一 Character 的关系阶段、当前态度和最近变化原因可跨故事读取；故事标记、选择、局部状态和结局不能跨故事读取。
- [ ] 玩家只与主动进入的 Character 对话；跨 Character 入口使用自然线索与可选角色头像，不自动跳转。
- [ ] 不同 Character 只读取自己可见的消息和故事事件，不因共享 StoryRun 获知未观察的信息。
- [ ] 首个体验完成一次“林晚照对话—主动拜访魏观海—主动返回—建议与玩家行动—林晚照自主决定—即时反馈”循环。
- [ ] 魏观海透露或保留信息的行为可以由长期关系和玩家本次言行解释，且最深线索仍不足以替林晚照决定。
- [ ] 第一章只能到达“认下家书 / 否认知情 / 请求复核”之一，并记录可追踪的触发依据。
- [ ] 三个第一章结果都停在“三日后复核”的活动状态，不显示为最佳、失败或最终结局。
- [ ] 关键状态只由已审核选择和确定性规则写回；自由输入与 AI 回应不能直接指定第一章结果。
- [ ] 林晚照、第一章内容和预览入口保持 draft，不进入公开发现或普通玩家运行时。
- [ ] 现有安妮故事、未来迁入的新“雪夜封宫”内容和既有 StoryRun 不被静默替换、重写或转入旧 Space 双轨。

## Out of Scope

- 首个切片实现完整册后流程、皇后结局、冷宫结局、后续章节或全部中间分支。
- 首个切片实现跨故事关系里程碑、完整事件记忆或关系回忆文案。
- 用户创作、发布或管理 Character、剧情线和结局。
- 运行时 AI 创建关键分支、永久状态、结局或 StoryWorld 正史。
- 后宫战斗、等级、装备、排行榜、公开玩家竞争或可刷取的好感数值。
- 独立故事大厅、世界目录或脱离 Character 的公开故事入口。
- 覆盖或改写“雪夜封宫”，使用 `content_version` 表示不同故事，或恢复旧 GameplayDefinition / Space 兼容合同。
