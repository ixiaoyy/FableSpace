- 360px 移动端和桌面端真实浏览器验收；

- 高风险删除前后核对完整 `git diff` 和目标文件清单。

## 8. 回滚点

- 领域与 API 完成但前端未切换：回滚新路由注册即可，不删除旧表。
- 前端切换完成但旧代码未删除：可回退前端入口，新运行时表保持不动。
- 旧代码与表清退：只通过明确迁移回滚或备份恢复，不依赖应用启动自动重建旧数据。
- 任一阶段验证失败时停止进入下一子任务，不用兼容适配器掩盖失败。

## 9. 当前执行顺序

活跃叶子任务只按以下顺序推进：

1. `00-bootstrap-guidelines`：补全项目真实开发规范，避免后续实现继续依赖空模板。
2. `07-23-system-llm-runtime`：收敛部署级模型配置并切断 owner / Space Token 依赖。
3. `07-24-player-continuity-integration`：接入登录恢复、跨设备续玩和会话失效保护。
4. `07-23-legacy-map-removal`：删除地图、坐标和 AMap 可达能力。
5. `07-23-legacy-space-contract-removal`：删除旧 Space 类型、路由和运行入口。
6. `07-23-legacy-schema-config-removal`：在显式迁移与授权边界内清退旧 Schema、环境变量和部署引用。
7. `07-23-story-platform-integration`：完成两个 P0 故事、前后端、移动端、文档与残留的最终验收。
8. `07-24-character-life-guidance-gameplay`：仅在 P0 主线稳定后进入 P2 规划与合同更新。

父任务只协调剩余子任务和跨层验收，不作为独立实现入口。
