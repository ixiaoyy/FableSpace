# S2-F 春季种子解锁、制作与种植闭环

日期：2026-09-10；本地 `main`，起点 `173bebc5`。续接当前技能任务已记录的连续开发授权。

## 行为变化

- 采集达到 1 级后，夜间报告列出 `野生种子（春）`；报告确认保存成功后才进入 `knownRecipes`。失败重试保留同一报告，不提前学习或重复加入。
- 配方消耗野山葵、水仙、韭葱、蒲公英各 1，产生春季种子 10。春季种子可按 35g 出货，但 `seedPrice:null`，种子店列表和领域购买入口均不出售。
- 春季种子播种为 `spring-forage`，经过 7 次有效浇水生长成熟；产物从四种春季野采中等概率选择。项目以世界种子、地块和播种日计算稳定结果，满包或保存失败重试不重抽。
- 成功收获增加种植 3 XP 与采集 2 XP，恢复为空耕地。春季野种不计入乌鸦机会，也不会成为乌鸦目标。
- 新增物品、非默认配方和内容定义，没有新增状态字段。封套 9 / 状态 21 不变，S2-E 同版本旧记录可继续；旧记录在下一次日结获得已达等级但未学习的配方。

依据为本日读取的 [Spring Seeds](https://stardewvalleywiki.com/Spring_Seeds)、[Crafting](https://stardewvalleywiki.com/Crafting)、[Farming / Experience Points](https://stardewvalleywiki.com/Farming#Experience_Points) 和 [Skills / Foraging](https://stardewvalleywiki.com/Skills#Foraging)。原作资料支持 10 个产物、7 天、四种等概率野采、35g、乌鸦豁免和 3 / 2 XP；本实现不声称复现原作内部随机数序列。

## 实际验证

- JSON 内容、35 个连续唯一排序值、配方材料 / 产物、四种候选和 16×16 / 16×24 像素矩阵解析通过。
- `artifacts/spring-seeds-s2f-2026-09-10/validate_spring_seeds.gd` 使用内存仓库执行 28/28：零级拒绝、日结失败重试、确认失败重试、四料原子制作、目标格冲突、制作保存重试、商店拒售、播种、6 / 7 天边界、四产物覆盖、乌鸦豁免、满包、收获保存重试、双 XP 和当前封套恢复。
- `validate_crop_art.gd` 通过七种作物逐日生长、漏浇、徽记和青豆复收检查；混合野种验证四个产物图标存在且不伪装为单一产物徽记。
- `typecheck:client`、`test:godot`（33 个规则案例 / 5 个哈希）和 `test:energy` 均通过。
- Web / Windows release 导出通过。隐藏 Web 隔离新档实际选择配方并点击背包空格：四种材料从 1 变 0，生成春季种子 10；背包详情显示 35g。临时经验、已知配方和材料已恢复，检查页及服务已关闭，最终两端产物已重建。

## 限制与回退

尚未实现野种品质、采集等级质量概率、Botanist / Gatherer、原作 RNG 序列、成熟后生成地面物品与磁吸、季末枯萎和其它季节野种。当前种子类别仍统一不可赠送，尚未按原作开放春季种子的全员讨厌送礼。真人连续 7 天种植、真机、长期存档和最终美术仍待验收。

无需数据库、依赖、配置或 schema migration。没有连接数据库、上传素材、提交、推送或部署。生产代码与配置暂存；测试、任务文档、素材记录和诊断脚本不自动暂存。

回退须一起移除春季种子物品、配方、作物 / 素材定义、可变收获与双 XP、商店空价保护和乌鸦豁免。含 `spring-seeds`、`spring-forage` 或已知配方的同版本开发档会被回退代码拒绝，不做自动迁移或物品转换；此前四种地面野采和 S2-C / D / E 不回退。
