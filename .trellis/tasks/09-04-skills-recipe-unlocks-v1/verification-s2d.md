# S2-D 水仙、韭葱与地面野采经验

日期：2026-09-10；本地 `main`，起点 `173bebc5`。续接当前技能任务已记录的连续开发授权。

## 行为变化

- `spring-wildflower` / `bamboo-shoot` 内容身份替换为 `daffodil` / `leek`，四张源地图、构建期类型、Godot 内容、委托和自定义居民礼物引用同步。地图稳定出生点 ID 与坐标保留；现有四区分布仍是待对齐差异。
- 水仙普通出货价 30，食用但不恢复体力；韭葱普通出货价 60，食用恢复 40。两者从当前地面随机野采点成功拾取时各增加采集经验 7；满包、同日重复拾取和保存失败不授予。
- `eat-item` 现在以可食用属性和恢复值分别判断；恢复值为 0 的物品仍可消费并返回中性提示 `ate-zero`，正恢复物品满体力时维持既有拒绝语义。界面将零恢复显示为 `食用`，不显示误导性的 `+0 体力`。
- 内容身份变化使用封套 9 / 状态 21。旧封套 8 / 状态 20 明确拒绝且不改写，不把旧物品静默解释为新物品。

数值依据为本日读取的 [Daffodil](https://stardewvalleywiki.com/Daffodil)、[Leek](https://stardewvalleywiki.com/Leek) 与 [Foraging / Experience Points](https://stardewvalleywiki.com/Foraging#Experience_Points)。页面资料与 1.6.15 机制相容，但本批没有运行原作可执行程序作逐帧核验。

## 实际验证

- 7 个修改 JSON / TMJ 文件解析通过；`godot:prepare` 生成 12 张地图并校验 43 张源图，生成目录确认水仙和韭葱各有 4 个出生点。
- `typecheck:client` 通过，包含内容 TypeScript、Godot 导入/解析和 120 帧无窗口启动。
- `artifacts/forage-s2d-2026-09-10/validate_forage.gd` 使用内存仓库执行 19/19：内容数值、地图数量、28 天可见点、两类 7 XP、93→100 即时升级、满包、重复拾取、失败重试、两种食用、当前恢复、旧档拒绝及原文保留。
- `test:godot` 通过：33 个规则案例、5 个稳定哈希，无失败。`test:energy` 通过；该检查原来只查技能页顶层文字，现有界面早已使用嵌套卡片，本批改为递归查找实际标签，没有改变技能规则。
- Web 与 Windows release 导出通过。恢复临时背包内容后又重新生成最终 Web 产物；Windows 产物从未包含临时物品。
- 隐藏浏览器使用独立端口和新 origin 检查实际 Godot Web：水仙、韭葱在快捷栏和背包中像素边缘清晰；详情分别显示 30g / `食用` 与 60g / `食用 +40 体力`。检查页及两个本地服务均已关闭。
- `git diff --check` 与暂存区格式检查通过。生产代码和配置按规则暂存；任务、规范、素材说明与诊断脚本未自动暂存。
