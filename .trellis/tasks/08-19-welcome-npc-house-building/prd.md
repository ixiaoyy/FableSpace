# 迎宾 NPC 免费建房

## Goal

让新玩家第一次进入镜像岛时，在一个安全的随机位置出生，并在正对面遇到迎宾 NPC。玩家通过对话获知选址流程，在世界中标记合法位置后，由 NPC 免费建成玩家唯一的私人住宅，并能在重连、重启后继续看到和进入自己的住宅室内。

## Background

- 产品合同已固定“迎宾 NPC 免费建房、每人一座私人住宅室内”，不引入材料、金币、多房屋或通用建造系统。
- 当前 `newPlayerSpawn(accountId)` 只在 `(280, 300)` 与 `(320, 300)` 两点间确定性选择，不是安全随机出生。
- 当前 `guide-npc` 固定在 `(280, 330)`；交互只赠送演示土豆、修改一个动态格并存档，没有建房能力。
- Prisma 基线已存在 `houses` 与 `world_occupancy`；`houses.owner_account_id` 唯一，数据库层已具备一人一屋和占地唯一约束，不新增 migration。
- 当前可运行地图是 32×32 瓦片样板；世界合同目标为 512×512、32×32 区块。随机出生和选址必须以运行时实际可加载、可行走区域为边界，不能随机到未加载或阻挡格。
- 用户新增要求：当前可玩区域需要增加河流等自然地形，使出生与选址不再发生在单一平地样板上。

## Requirements

### 首次出生与迎宾 NPC

- 随机出生仅发生在新玩家首次创建存档时：从服务端审核过的可行走、未占用安全位置中选择；不得落入阻挡、房屋、地图外或未加载区域。
- 迎宾 NPC 在该玩家正对面相邻的安全位置出现，并朝向玩家；不能与玩家、已有房屋或阻挡格重叠。
- 迎宾 NPC 的引导属于玩家 onboarding 状态，不把同一个公共 NPC 瞬移给所有玩家，也不能让其他玩家的 onboarding 改变自己的流程。
- 已有存档玩家继续从持久化位置恢复，不因普通重登重新随机出生或重复创建迎宾流程。
- 尚未建房的玩家中途退出后可继续引导；房屋建成时 NPC 向该玩家道贺、结束个人实例并消失，以后重登不再生成。

### 当前地图地形补充

- 在不扩建完整 512×512 世界的前提下，为当前已加载可达地图增加固定虚构河流和至少一个可通行桥/浅滩。
- 河水属于基础 Tilemap 地形，不入数据库；桥/浅滩提供明确跨越点，不实现游泳、钓鱼、水位或程序化河网。
- 安全随机出生、NPC 相邻位置、房屋 footprint 和房门可达性校验必须把河水视为阻挡，不得出生或建房在水面。
- 优先复用已登记 Ninja Adventure tileset 的审核区域，不新增来源不明或 Git 图片二进制。
- 也可采用 CC0、CC-BY、MIT、BSD、Apache-2.0 等允许商用与再分发的成熟开源现成素材；CC-BY 必须随产品署名。NC、ND、来源不明和未批准强 copyleft 禁止采用。

### 对话与选址

- 玩家主动点击/动作键与 NPC 对话，NPC 欢迎玩家来到镜像岛，并明确提示“去找一个喜欢的位置并标记，我会免费帮你盖房”。
- 对话后 NPC 向尚未建房的玩家发放一个“选址木桩”物品，复用 RPGJS Items/Inventory；不自研通用建造编辑器。
- 玩家走到目标位置、面向预期入口方向后使用木桩；玩家面前一格作为房门锚点，显示固定 4×6 住宅 footprint 和入口方向预览。
- 所有住宅固定正面朝南，木桩标记南侧房门格；不支持四向旋转。
- 选址范围覆盖整座当前可达岛屿，不设置出生点半径；未加载区域仍不可选。
- 本任务不扩建完整 512×512 地图；住宅服务按 512×512、32×32 区块合同设计，但选址只接受当前已加载可达区域。
- 玩家确认预览前不写数据库、不广播房屋；取消后保留木桩和选址机会。
- 服务端必须验证地图边界、可加载区域、基础阻挡、河水/桥、现有 `world_occupancy`、footprint 内稀疏 `world_cells`、住宅入口可达性和玩家已有住宅。
- 非法位置只返回明确原因并保留选址机会；不得占地、扣物品或生成半座房屋。
- 合法确认后立即建成并播放简短像素施工效果；不要求玩家返回 NPC，不引入施工等待或 NPC 寻路。
- 建成后玩家留在房门外，先看到住宅与 NPC 道贺，再由玩家主动点击房门进入室内；不自动传送。

### 免费建房与持久化

- 合法确认后，服务端在同一事务内创建一条 `House` 和完整 footprint 的 `WorldOccupancy`；并发争抢同一位置时只能一个成功。
- 数据库提交成功后才向 RPGJS room 广播住宅外观和碰撞；失败时不广播临时房屋。
- 每个玩家最多一座住宅；已有住宅再次与 NPC 对话时，NPC说明已经建好并引导玩家回家，不重复创建。
- 房屋外观优先选用成熟开源现成像素素材，不限于当前 Ninja Adventure；采用前必须核对官方来源、固定版本/快照、许可证、商用与再分发兼容性，并登记不可变对象与媒体清单。
- 房屋位置、外观版本和占地在进程重启、玩家重连及区块重新加载后恢复。

### 私人住宅室内

- 房门可由建造者进入其私人住宅室内；其他玩家不能进入，也不获得公共住宅室内实例。
- 其他玩家点击房门时显示“这是其他岛民的私人住宅”之类的简短提示，但仍禁止进入。
- 室内优先选用与房屋外观一致的成熟开源现成素材；若当前 `interior-floor.png` 与 `wall.png` 视觉更匹配可继续复用，并提供明确出口返回该住宅门前。
- 本任务只提供一套固定住宅外观和一套固定室内，不做家具摆放、升级、装饰、扩建或访客权限。

## Acceptance Criteria

- [ ] 新账号首次进入时落在安全随机出生点，迎宾 NPC 位于玩家正对面相邻安全格并可立即对话。
- [ ] 同一账号重登恢复存档位置，不重复随机出生；尚未完成建房时仍能继续 onboarding。
- [ ] 当前地图具有固定河流和至少一个可通行桥/浅滩；河水阻挡移动、出生与建房，桥保持可走。
- [ ] NPC 对话完整表达欢迎、选址、标记和免费建房，不再执行演示土豆/演示地块行为。
- [ ] NPC 幂等发放选址木桩；玩家能看到固定 footprint/入口并确认，取消/非法位置保留木桩且不产生数据库写入。
- [ ] 合法位置事务性创建唯一 `House` 与所有 `WorldOccupancy`，提交后才显示；并发冲突不会重叠或生成半成品。
- [ ] 建成后玩家留在门外，NPC 道贺并结束个人实例；该账号以后重登不再生成迎宾 NPC。
- [ ] 住宅外观、碰撞和占地在重连、进程重启与区块重载后保持一致。
- [ ] 建造者可由房门进入唯一私人 room 并从出口返回；非建造者无法进入且收到私人住宅提示。
- [ ] 已有住宅玩家再次找 NPC 不会获得第二座房屋。
- [ ] 使用既有九表基线，不新增 migration；论坛、Keycloak、R2 和游戏媒体清单边界不被破坏。
- [ ] 自动检查仅覆盖程序语法、TypeScript 类型和必要构建边界，不为完整玩法、多人冲突或数据库行为扩建大规模自动测试。
- [ ] 安全出生、NPC 引导、合法/非法选址、一人一屋、占地冲突、重载恢复与室内所有者校验由人工测试反馈验收。
- [ ] 最小类型检查与客户端/服务端构建通过；本任务不以新增自动化 PostgreSQL 集成测试作为交付门槛。

## Out of Scope

- 建筑材料、金币、施工时间、动画队列、体力或任务奖励。
- 多房屋、房屋升级、移动/拆除、家具、装修、扩建和访客权限。
- 私有化住宅周边公共土地、领地保护、交易或通用建造系统。
- 公共住宅室内、玩家碰撞、现实地图或定位。
- 完整 512×512 程序化河网、游泳、钓鱼、船只、洪水和动态水位。
