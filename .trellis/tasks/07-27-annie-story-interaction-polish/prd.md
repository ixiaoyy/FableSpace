# 安妮故事交互细节与史料表面

## Goal

在完整剧情和受控自由对话稳定后，补齐安妮线路的选择反馈、模型等待、时间线
定位、移动端输入体验和玩家主动打开的历史参考表面。

## Requirements

- 本任务依赖 `07-23-broad-street-story` 和
  `07-27-annie-dialogue-guardrails` 完成。
- 关键选择提交后必须呈现安妮的明确回应或已审核角色动作，不能只剩系统叙事。
- 模型等待、成功、失败和会话失效状态必须真实可见；失败不得伪装已发送。
- 新消息和节点推进后保持可预测的时间线定位，不让移动端用户手工寻找最新内容。
- 390×844 与窄屏软键盘场景下，选择和输入区可达、无横向溢出。
- 增加由玩家主动打开的历史参考表面，按剧情阶段展示
  `史实 / 剧情设定 / 待核验` 和来源；不在主页面倾倒说明文案。
- 不显示 affinity 数值，不允许回退关键选择。
- 不生成或替换图片；视觉资产由后续独立任务处理。

## Acceptance Criteria

- [x] 每个关键选择后都有可归因的角色反馈和明确推进状态。
- [x] 模型等待、失败重试和会话失效不会重复提交消息或选择。
- [x] 时间线在新消息与节点推进后定位稳定，键盘操作可用。
- [x] 历史参考表面按节点解锁且不把剧情设定包装为史实。
- [x] 390×844 和桌面浏览器真实验收通过，无横向溢出。
- [x] `npm --prefix .\apps\web run typecheck` 和 build 通过。

## Out of Scope

- 剧情内容、LLM 后端边界、数据库迁移和图片生成。
