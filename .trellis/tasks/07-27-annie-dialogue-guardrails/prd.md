# 安妮自由对话边界与关系反馈

## Goal

在完整安妮剧情稳定后，让自由输入真正形成受控的角色演绎与小幅关系反馈，
同时阻止模型补写未核验历史、越过儿童内容边界或直接推进关键剧情状态。

## Requirements

- 本任务依赖 `07-23-broad-street-story` 完成并通过历史对抗式自审。
- 使用部署级系统 LLM 配置，不新增 owner / StoryWorld 私有配置或计费能力。
- 输入上下文必须包含锁定内容版本、Character、固定 PlayerRole、当前节点、
  关系阶段、已确认正史、故事 flag 和受限的最近可观察事件。
- 自由输入未匹配已审核动作时只能形成普通对话；不得改变节点、关键选择、
  故事 flag、固定正史或结局。
- 模型输出必须经过可观察的边界校验；历史断言、现代医学结论、真实人物
  无出处原话、儿童不当内容和替玩家行动不得直接持久化。
- 自然对话可以产生有理由、可追踪且不超过
  `natural_turn_max_delta` 的小幅关系候选；重复闲聊不得刷出重大关系阶段。
- 为正常对话、诱导改史、伪造来源、现代知识、关系刷取和儿童安全建立固定
  对抗验收语料；验证使用 fake responder，不依赖真实数据库。
- 不修改剧情图、前端或图片资产。

## Acceptance Criteria

- [ ] 合法自由输入产生符合安妮语言、当前节点和关系阶段的短回应。
- [ ] 越界输出被拒绝或替换为受控安全结果，且不持久化违规文本。
- [ ] 自由输入不能推进关键状态；关系变化有上限、原因和来源事件。
- [ ] 重复或同义闲聊不能无成本进入最高关系阶段。
- [ ] 对抗验收覆盖历史完整性和儿童安全并记录结果。
- [ ] 缺失/非法 LLM 配置继续返回不泄密的受控错误。
- [ ] Python 最小检查与定向运行时验证通过。

## Out of Scope

- 关键选择剧情内容、页面交互、史料抽屉和视觉素材。
- 让 LLM 创建章节、结局、正史或任意永久状态。
