# 将宫廷故事改编为真实历史事件

## Goal

把当前纯架空的“长明宫·雪夜诏书”替换为基于真实宫廷事件的历史改编，并让现有“内侍 / 公主”两个角色位由同一事件中的成年真实人物承担。当前推荐骨架是 713 年先天政变，角色为高力士与太平公主。

## Background

- 1620 年“移宫案”方案已被用户撤回；真实皇八妹在相关材料中被称为“幼女”，不能作为平台的真实儿童互动 Character。
- 用户不接受只给既有原创角色换一组原创姓名，也不接受“王安 / 李选侍”组合，要求更换故事。
- 先天政变能够保留现有“宫内内侍 / 成年公主”双视角：正史明确记载高力士参与玄宗一方的先制行动，太平公主则是另一方的核心人物。
- 旧故事的架空皇帝、秘诏、雪夜与水门情节均无史料基础；新版本只保留双 Character、双 PlayerRole、关系与分支运行框架，不保留这些剧情事实。
- 用户仍要求角色改名并删除旧故事素材。两张旧 Character 立绘和两张带有“架空雪夜”视觉的 PlayerRole 头像都与新唐代故事冲突；新素材安全上线后，精确删除这四张旧图、本地旧 prompt sidecar、manifest 旧项与对象存储对应旧对象。

## Requirements

- 以 713 年先天政变作为唯一主骨架；太平公主失败及其随后被赐死是所有分支不可改变的固定结局，避免描写处决细节。
- 关键固定史实至少由两个相互独立的可靠来源支撑，其中至少一个是一手史料、权威馆藏、大学或同行评审资料。
- 将时间、地点、参与者、可证实同行关系、制度阶段与公开结果记录为 `史实`；太平公主一方“谋废”“举兵”等定性须记录史书叙事立场，不由系统补写私人动机。
- 两个公开 Character 改为真实成年人高力士、太平公主。开场和自由回应只使用带固定标识的第三人称剧情转述，不生成第一人称原话；`motive`、`secret` 与系统提示必须禁止无来源私密心理和确定性阴谋补写。
- 玩家身份只可处理传话、名册、门禁记录、见闻核对与原创普通宫人的局部处境；不得改变先制行动、太平公主失败或唐玄宗掌权等公开结果。
- 所有结局共享同一真实结果，只允许玩家留下的记录方式与原创普通人物的局部处境分歧；真实 Character 的关系数值和阶段保持不变。
- 保留现有 StoryWorld ID、Character ID、PlayerRole ID 与运行协议作为不透明技术标识，不修改 Schema、迁移、登录协议或 StoryRun 状态。用户随后单独授权以受控工作流精确替换生产 `managed_story_worlds` 中该 StoryWorld 文档；除这一行替换及其结果校验外不做任意数据库探测或数据操作。
- 内容版本升级；标题、摘要、Character 身份、章节、结局、CanonEntry、首页和权威文档保持一致，不残留“曜宁朝”“长明宫”“雪夜封宫”“未宣诏书”等旧内容。
- 四张新图须采用唐代历史化视觉和新的不可变对象 key；高力士不得沿用明代掌印太监形象，太平公主不得沿用架空雪夜公主形象，两个原创 PlayerRole 头像不得保留雪夜或后世服饰。
- 新图必须先生成、审核、上传并完成引用切换；随后只精确删除以下旧对象及其 manifest 项和 prompt sidecar，不删除玩家身份头像或其他素材：
  - `app/assets/home-story-bookshelf/v1/characters/char_story_palace_eunuch_wei.webp`
  - `app/assets/home-story-bookshelf/v1/characters/char_story_palace_princess_xiao.webp`
  - `app/assets/story-worlds/story_palace_snow_edict/player-roles/little-eunuch/v1/avatar.webp`
  - `app/assets/story-worlds/story_palace_snow_edict/player-roles/little-palace-maid/v1/avatar.webp`

## Acceptance Criteria

- [x] 用户确认采用 713 年先天政变，并接受太平公主失败是所有分支不可改变的固定结果。
- [x] 研究台账逐条区分 `史实`、`剧情设定`、`待核验` 与“史书中的指控/定性”，每个关键史实满足双来源要求。
- [x] 高力士与太平公主均按 713 年可核验身份、公开行动和关系呈现；第三人称剧情转述不冒充原话，系统不生成无来源私密心理。
- [x] 玩家选择只改变查证路径、记录方式与关系体验，不阻止或促成真实政变，也不改变太平公主结局。
- [x] StoryWorld、章节、结局、CanonEntry、首页与权威文档没有残留旧架空故事内容。
- [x] 内容版本升级，稳定技术 ID 的兼容边界明确；仅按用户后续授权替换一个生产托管内容文档，不修改 Schema、迁移或已有 StoryRun 状态。
- [x] 四张新图使用新的不可变 key 并通过视觉与 CDN 核验；所有引用切换完成后，四个旧远端对象、manifest 旧项和旧 sidecar 精确删除。
- [x] 完成 Python compileall、StoryWorld 注册表/引用/版本检查、前端 typecheck/build 与双身份浏览器试玩。
- [x] 完成历史内容对抗式自审，并给出 PASS / FAIL / BLOCKED 与证据。

## Out of Scope

- 把太平公主在 713 年的失败改成获胜、逃亡或与玄宗和解。
- 描写处决细节、血腥猎奇或把玩家变成亲手杀人的行动者。
- 将真实人物的剧情转述宣传为史料引文，或把后世定性直接写成已证实的私密阴谋。
- 删除安妮立绘、UI 素材或未列入白名单的远端对象。
- 修改数据库中的 Character ID、StoryRun、PlayerStoryState 或历史运行状态。

## Notes

- 需求来源：用户 2026-08-05 明确撤回移宫案方案并要求“换个故事”，随后认可 713 年先天政变方案。
