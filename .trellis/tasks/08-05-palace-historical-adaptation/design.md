# 宫廷历史改编设计

## 当前状态

用户已确认 713 年先天政变及其固定悲剧结局，任务恢复生产实施。

## 推荐改编映射：713 年先天政变

| 现有结构 | 改编方向 |
|---|---|
| 架空长明宫雪夜 | 唐长安宫城，以武德殿、虔化门、内客省与朝堂等经核验地点为准 |
| 魏观海掌印封门 | 改为真实内侍高力士；只呈现史书可证的玄宗近侍身份与先制行动，不补写私人秘密 |
| 萧明珠公主强闯 | 改为成年真实人物太平公主；呈现其公开政治位置和史书记载的阵营，不把史书定性自动当成内心独白 |
| 皇帝昏迷与秘密诏书 | 改为玄宗与太上皇并存的权力结构、禁军与宫门控制，不虚构决定皇位的秘诏 |
| 小太监 / 小宫女 | 改造为符合唐代宫廷制度的低阶成年内侍 / 宫人；确切职名核验不足时使用一般描述 |
| 玩家决定开门、宣诏 | 改为核对口信来源、门禁记录、禁军名册与传言归属 |
| 四个历史分歧结局 | 固定先制行动与太平公主结局，只让证词保存方式和原创普通宫人处境分歧；真人关系不变 |

## 真人 Character 边界

- Character 所需 `motive` 不写确定性私密动机，只描述可证实的公开立场和行动目标。
- `secret` 字段改作明确限制：没有可证实的私人秘密，模型不得生成或暗示一个“真正阴谋答案”。
- `opening_line` 与后续生成回应须以固定“剧情转述（非史料原话）”前缀和 Character 姓名作第三人称转述；输出校验拒绝第一人称、引号与生成式动作。
- 太平公主失败与被赐死是固定公开结果，关系分值不得改写或美化该结果；叙事避免处决过程的感官描写。

## 兼容与版本

- StoryWorld、Character、PlayerRole 的持久化 ID 作为不透明标识保留，避免在无数据库授权和迁移评审时破坏既有 StoryRun。
- 公开短路由切换为 `gao-lishi` / `taiping-princess`；持久化 ID 保留为不透明标识，不为旧展示名建立兼容路由。
- 新 `content_version` 锁定唐代改编；既有轮次仍由原版本合同处理，实施前核对当前版本加载行为。

## 素材切换与删除顺序

1. 为高力士、太平公主及两个原创成年 PlayerRole 生成并人工视觉核验方形 WebP，新图使用唐代服饰和新对象 key。
2. 上传新对象并验证 CDN、MIME、字节数与 SHA-256；代码和文档全部切到新 URL，更新 manifest 与 sidecar。
3. 完成构建、引用审计和线上切换后，按白名单与旧哈希精确删除四个旧对象。
4. 删除旧 manifest 项和四个旧 prompt sidecar；不触及安妮立绘、UI 图或其他素材。

远端删除不可恢复。缺少可用凭据、未完成线上切换或无法核对对象哈希时，远端步骤必须标记 BLOCKED，不能提前删旧图造成线上断图。

## 回滚边界

- 太平公主失败与被赐死的固定结局不得回滚成可改变分支；若产品方向改变，应停止发布并另立架空题材任务。
- 如史料无法同时支持两名真实 Character 的行动边界，停止发布并回到事件选择，不用原创桥段填补关键前提。
- 不删除注册表入口、稳定 ID、路由映射或运行状态。
